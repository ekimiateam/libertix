Installez Linux depuis Windows Install Linux from Windows

Une application Windows gratuite qui pose Linux à côté de votre système actuel. Aucune clé USB à graver, aucun réglage de firmware à trouver, et une installation qui sait revenir en arrière. A free Windows application that installs Linux next to your current system. No USB drive to burn, no firmware settings to hunt for, and an install that knows how to undo itself.

fonctionnementhow it works

Trois moments décident de tout. Three moments decide everything.

Installer Linux à côté de Windows n'est pas difficile en soi. Ce sont les étapes autour qui découragent, et ce sont celles-là que Libertix prend en charge. Installing Linux next to Windows is not hard in itself. It is the steps around it that put people off, and those are the ones Libertix takes over.

Avant d'écrire quoi que ce soitBefore anything is written

Libertix inspecte la machine et a le droit de dire non. Firmware, mémoire, chiffrement du disque, contrôleur de stockage, espace réellement libérable. Une configuration qu'il ne saurait pas restaurer est refusée, avec un code d'erreur exploitable. Libertix inspects the machine and is allowed to say no. Firmware, memory, disk encryption, storage controller, space that can genuinely be freed. A layout it could not restore is refused, with an error code you can act on.

  • BitLocker entièrement déchiffréBitLocker fully decrypted
  • Démarrage sécurisé compatibleSecure Boot compatible

La place que vous accordezThe space you give it

Vous choisissez, Libertix vérifie. Il garde toujours de quoi laisser Windows respirer, refuse une taille qui mettrait le système en difficulté, et prépare lui-même l'environnement d'installation sur le disque. Rien à graver, rien à brancher. You choose, Libertix checks. It always keeps enough room for Windows to breathe, refuses a size that would leave the system struggling, and prepares the install environment on the disk itself. Nothing to burn, nothing to plug in.

Le menu, à chaque allumageThe menu, every time you start

Windows n'est pas remplacé, il devient une entrée. Le menu est installé puis vérifié, et trois gardes le maintiennent en place quand le noyau, GRUB ou le chargeur signé sont mis à jour. Tant que l'installation n'est pas finie, elle reste annulable, et la restauration est contrôlée avant d'être annoncée. Windows is not replaced, it becomes an entry. The menu is installed and then verified, and three guards keep it in place when the kernel, GRUB or the signed loader are updated. Until the install finishes it stays reversible, and the restore is checked before it is reported.
