Automated installation

Mint then Zorin, Windows-first then Linux-first: three VMs in parallel for each scenario. Usual snapshot, space taken from Windows, both shares enabled, monitoring enabled and no injected fault. Each scenario ends by uninstalling Linux through Libertix, then a Windows reboot without OS selection and a verification of the restored state. If the migration is checked, the campaign tests a custom image. The single-scenario options below are disabled.
